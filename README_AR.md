# منصة تعلّم — نسخة أولية قابلة للتشغيل

## قبل التشغيل
- تحتاج Node.js 18 أو أحدث.
- هذه نسخة أولية للتجربة والمراجعة، وليست جاهزة للنشر التجاري قبل الاختبار الأمني والتشغيلي.
- الدفع يدوي: لا توجد بوابة دفع إلكترونية ولا تحقق تلقائي من التحويلات.
- روابط الفيديو تُضاف من لوحة الإدارة. لا ترفع فيديوهات كبيرة على نفس خادم التطبيق.

## التشغيل على Windows
1. فك ضغط المجلد.
2. انسخ `.env.example` إلى ملف جديد اسمه `.env`.
3. غيّر `SESSION_SECRET` إلى قيمة عشوائية طويلة، وغيّر `ADMIN_PASSWORD` إلى كلمة مرور قوية خاصة بك. لا تشارك ملف `.env`.
4. افتح CMD داخل مجلد المشروع.
5. نفّذ: `npm install`
6. ثم: `npm start`
7. افتح `http://localhost:3000`

إذا لم يكن npm في PATH، شغّل:
`"C:\\Program Files\\nodejs\\npm.cmd" install`
ثم:
`"C:\\Program Files\\nodejs\\npm.cmd" start`

## تسجيل الدخول للإدارة
استخدم القيم التي وضعتها في `.env`: `ADMIN_EMAIL` و`ADMIN_PASSWORD`.
يتكون حساب المدير تلقائيًا عند أول تشغيل لقاعدة البيانات فقط. لو تغيّرت كلمة المرور في `.env` بعد إنشاء الحساب، فلن تتغير تلقائيًا في قاعدة البيانات.

## إعداد الدفع
عدّل هذه القيم في `.env`:
- `PAYMENT_PHONE`: رقم Vodafone Cash.
- `INSTAPAY_HANDLE`: رقم الهاتف أو معرّف InstaPay الصحيح.
- `WHATSAPP_NUMBER`: رقم واتساب بصيغة دولية دون + أو مسافات، مثال مصر `2010xxxxxxxx`.
تأكد من أن الأرقام تخصك فعلًا قبل مشاركة الموقع. لا تضع PIN أو OTP أو بيانات دخول مالية.

## مميزات النسخة
- صفحة رئيسية وتصميم متجاوب.
- وضع داكن/فاتح محفوظ في المتصفح.
- تسجيل طالب وتسجيل دخول.
- كورسات عامة مصنفة حسب المادة.
- طلب اشتراك مع دفع يدوي.
- لوحة إدارة لإضافة الكورسات والدروس، ومراجعة الاشتراكات.
- قاعدة بيانات SQLite وجلسات مخزنة محليًا.

## ما يجب إنجازه قبل النشر
- اختبارات فعلية على جميع المسارات والمتصفحات والهواتف.
- ضبط HTTPS وSESSION_SECRET وبيئة الإنتاج.
- سياسة خصوصية وشروط استخدام وبيانات تواصل حقيقية.
- تحديد صلاحيات المدرسين المتعددين إن كان كل مدرس سيملك حسابًا مستقلًا؛ النسخة الحالية فيها مدير واحد وإدارة مركزية.
- تخزين فيديوهات آمن/خدمة فيديو خارجية، وعدم اعتبار رابط عام وسيلة حماية للمحتوى.
- نسخ احتياطي دوري واختبار الاستعادة.
- مراجعة أمان احترافية وتحديد مسؤوليات معالجة البيانات.
